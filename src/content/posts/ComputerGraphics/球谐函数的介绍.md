在您的计算机图形学之旅中，您最终会遇到一些提及球谐函数的论文或代码。它们确实是一个非常实用的工具：只需几个系数，它们就能让我们对一个定义在球面上的函数进行近似。这对于模拟复杂光照非常有用。

虽然球谐函数是一个研究得非常透彻的课题，但尝试理解它们仍然可能有点令人望而生畏。然而，我认为理解球谐函数在实时计算机图形学领域的应用并不那么困难。

在这篇文章中，我将尝试以我希望被解释的方式来解释球谐函数。我希望到文章结束时，读者能够准备好消化使用或讨论球谐函数的更高级的技术材料。

虽然读者被期望对实时渲染、线性代数和积分有一定的基本了解，但这并不是什么太疯狂的事情——我们不会进行任何严格的证明，而我们进行的任何推导都是简单的基本代数。

## 我们为什么要关心？

在我们开始之前，我想应该正确地解释一下，为什么我们作为计算机图形领域的从业者，会对球谐函数感兴趣。

任何将某种量/值与三维空间中某个方向相关联的函数都可以被视为定义在单位球域上的函数。实际上，“方向”是一个单位向量，而该向量的终点始终是原点为中心的单位球面上的某一点。在接下来的内容中，我们将交替使用“方向函数”、“球面函数”和“单位球面函数”这些术语。

恰好的是，任何定义在球面上的连续函数都可以表示为某些特殊多项式的无限加权之和。这些多项式实际上就是我们所说的“球谐函数”。通过截断该求和使其有限，我们可以逼近所讨论的函数。

但这为什么有趣呢？因为多项式易于计算，而定义在球面域上的非平凡函数在计算机图形学中经常出现。

例如，辐射度 $L_{i}(p,\overrightarrow{\omega_{i}})$ 是一个定义在球面上的函数：它告诉我们从给定方向 $\omega_{i}$ 到达点 $p$ 的光量是多少。立方体贴图可以被认为是这种函数的“表格化”形式。给定点的辐照度也可以被视为方向函数（即“如果表面法线朝向特定方向，固定点的辐照度会是多少”）。

仅通过相加一些多项式就能近似一个潜在的复杂光照环境，这是一个非常有吸引力的想法。但除了光照之外，其他事物也可以表示为定义在球面上的函数。

例如，球谐函数可以用来近似网格或体积在每个表面点沿给定方向的厚度。通过这种方式近似的厚度可以被烘焙到纹理贴图集中，并可用于模拟次表面散射等现象。

因此，球谐函数除了用于光照之外还有其他用途，尽管在本文中我们将主要集中讨论光照的应用案例。

## 球谐函数的定义

到目前为止，我们希望已经足够兴奋和有动力去学习了，那么让我们从一些定义开始。再次强调，我不会进行非常严格的数学推导——我的目标只是提供足够的细节，以便你，作为读者，能够阅读和理解引用球谐函数的代码和论文。

### 函数空间及其基 (basis)

从线性代数中，我们熟悉“线性”或“向量”空间及其“基”的概念。为了能够正确定义球谐函数，我们需要为函数世界构建类似的结构。[Kevin Cassel 的视频](https://www.youtube.com/watch?v=177zEpIwI68)很好地解释了这些概念。

首先，我们将定义在某个域上的函数集视为一个“空间”。严格来说，这里的所有定义都要求我们提及我们讨论的函数所定义的域（你将注意到上面链接的视频就是这样做的）。然而，在我们的用例中，域始终是单位球，所以我们不会提及它。

在线性代数中，如果集合中的某个向量不能表示为该集合中其他向量的线性组合，则称该向量集合“线性无关”。换句话说，对于任何 $\overrightarrow{v_{i}}$, 都不存在系数 $a_{1},\dots, a_{n}$ 使得 $\overrightarrow{v_{i}}=a_{0}\overrightarrow{v_{0}}+\dots+a_{n}\overrightarrow{v_{n}}$。

同样地，函数集 $f_{0}(x),f_{1}(x)\dots,f_{n}(x)$ 线性无关，如果该集合中的任何一个函数都不能表示为该集合中其他函数的线性组合：对于任意 $f_{i}$，都不存在系数 $a_{0},a_{1},\dots,a_{n}$ 使得 $f_{i}(x)=a_{0}f_{0}(x)+\dots+a_{n}f_{n}(x)$。

在线性代数中，我们有内积（或点积）的概念：对于给定的向量对 $\overrightarrow{p}=(p_{0},p_{1},\dots,p_{n})$ 和 $\overrightarrow{q}=(q_{0},q_{1},\dots,q_{n})$，内积 $\overrightarrow{p}\cdot \overrightarrow{q}$ 定义为：
$$
\overrightarrow{p}\cdot \overrightarrow{q}=\sum_{i=0}^{n}p_{i}q_{i}
$$

对于函数 $f$ 和 $g$，它们的内积 $\langle f,g\rangle$ 定义为它们乘积在函数定义域上的积分：
$$
\langle f,g\rangle = \int f(\omega)g(\omega)d\omega
$$

直观上，如果你将一个函数视为具有无限维度的向量，并将积分视为类似于求和，那么这两种内积概念之间的平行关系就变得显而易见了。

类似地，一个函数的**范数**(<font color="#4dfe50">norm</font>)是其与自身内积的平方根。
$$
||f||=\sqrt{ \langle f,f\rangle }
$$

由此，应该很容易看出“正交归一函数集”是什么：它是一组函数，其中任意函数与其自身的内积为 1（这就是“归一”的部分），而与集合中其他任意函数的内积为 0（这就是“正交”的部分）。

对于线性空间，“正交归一基”是一个正交归一、线性无关的向量集，使得空间中的任何向量都可以唯一地表示为基向量线性组合的结果。

类似地，对于函数空间，“正交归一基”是一个正交归一、线性无关的函数集合，使得空间中的任何函数都可以唯一地表示为基函数的线性组合。

然而，需要指出的是，对于函数空间，基集将永远是无限的！再一次，如果我们把函数看作具有无限维度的向量，这就很合理了：我们知道对于 N 维向量空间，基集将始终包含 N 个元素，因此一个"无限维向量空间"具有无限基集是很合理的。

### 球谐函数

球谐函数（简称“球谐”）是一组定义在球面上的特殊函数，它们构成了整个定义在球面上的连续函数空间的标准正交基。

退一步思考上述定义的启示。这意味着，定义在球面上的连续函数，无论多么复杂或难以计算，都可以表示为球谐函数的无穷加权之和。

这一事实具有极大的实际应用价值——前提是球谐函数本身易于计算，并且存在有效的权重/系数求解方法。

正如我们之前提到的，球谐函数是多项式，因此实际上它们很容易计算。而且确实存在一种找到系数的方法，我们将在后面讨论。

好的，到目前为止这很有道理，但我们无法在计算机上处理无限数量的系数。我们必须存储有限数量的它们。这没关系，我们并不介意处理近似值。但我们应该存储多少系数，哪些系数？以及我们通过舍弃一些系数会丢失哪些信息？这个问题的答案将在下一节中给出。

### 球谐函数的次数和阶数

在我向你展示球谐函数的实际样子之前，我们需要谈谈这组函数是如何组织的。

球谐函数通常会被划分为若干个带编号的组，这些组通常称为“频带”。每个频带都对应一个整数 $\ell \in \{0,1,2,\dots\}$。这个整数称为该频带中函数的“次数”。次数为 $\ell$ 的频带包含 $2\ell+1$ 个函数。按照惯例，次数为 $\ell$ 的频带中的函数用从 $-\ell$ 到 $\ell$ 的整数作为索引，而这个索引称为函数的“阶”。

附注：我见过一些资料使用 “order” 来指代本文中称为 “degree” 的概念，并使用 “phase” 来指代本文中称为 “order” 的概念。本文不会采用这种术语，但需要注意它的存在，以免混淆。

一个次数为 $\ell$ 、阶为 $m$ 的球谐函数通常记作：$Y_{\ell}^{m}$。

查看按频带和阶排序的各种球谐函数的可视化图是富有启发性的：

![image.png](https://raw.githubusercontent.com/SilverStr1ng/Images/master/Images/20260415152323.png)

从上面的插图可以看出，次数较小的球谐函数捕捉更大的（或，“低频”）细节，而次数较大的球谐函数捕捉更小的（或，“高频”）细节。

也就是说，$m$ 表示的是**同一个频带 $\ell$ 下，不同的球面变化模式**。简单理解为：**上图中每一行中不同的小球，就是不同的 $m$ ，** 更准确的说，**$m$ 是同一频带中不同基函数的编号。**

回想我们之前提出的问题：截断无限和会丢失什么类型的信息？上面的图很清楚：我们丢失了我们试图逼近的函数内部小尺度变化的信息。换句话说，我们丢失了细节。

如果我们试图逼近的函数是“低频”（即变化缓慢），我们应该能够仅存储前几个频带的系数。在实时计算机图形的实际应用中，我们很少会超过低阶频带，而且，即使只是次数为 0 的频带就足够许多应用了。

### 对球谐多项式的一个观察

到目前为止，我们只讨论了球谐函数，但我们还没有看到它们实际的样子。现在，我们将查看前三个频段内的球谐函数的多项式形式，因为我们将在接下来的示例中使用这些形式。

这里有一些计算这些多项式的代码。它使用 JavaScript 编写，因为我们的示例将在浏览器中运行。
```javascript
// Having these constants makes writing down the basis functions easier.
const RECIP_PI = 1/Math.PI;
const C = [
  Math.sqrt(RECIP_PI) * 0.5,
  Math.sqrt(3 * RECIP_PI) * 0.5,
  Math.sqrt(15 * RECIP_PI) * 0.5,
  Math.sqrt(5 * RECIP_PI) * 0.25,
  Math.sqrt(15 * RECIP_PI) * 0.25,
  Math.sqrt(70 * RECIP_PI) * 0.125,
  Math.sqrt(105 * RECIP_PI) * 0.5,
  Math.sqrt(42 * RECIP_PI) * 0.125,
  Math.sqrt(7 * RECIP_PI) * 0.25,
  Math.sqrt(105 * RECIP_PI) * 0.25];
  
// SH basis functions up to degree l=3. 
// Source for SH basis function definitions:
// "Stupid Spherical Harmonics Tricks", Peter-Pike Sloan, 2008
function y00(x,y,z) { return C[0]; }
function y_11(x,y,z) { return C[1] * y; }
function y01(x,y,z) { return C[1] * z; }
function y11(x,y,z) { return C[1] * x; }
function y_22(x,y,z) { return C[2] * y * x; }
function y_12(x,y,z) { return C[2] * y * z; }
function y02(x,y,z) { return C[3] * (3 * z * z - 1.0); }
function y12(x,y,z) { return C[2] * x * z; }
function y22(x,y,z) { return C[4] * (x*x - y*y); }
function y_33(x,y,z) { return C[5] * y * (3*x*x - y*y); }
function y_23(x,y,z) { return C[6] * z * (y*x); }
function y_13(x,y,z) { return C[7] * y * (5*z*z -1); }
function y03(x,y,z) { return C[8] * z * (5*z*z - 3); }
function y13(x,y,z) { return C[7] * x * (5 * z * z - 1); }
function y23(x,y,z) { return C[9] * z * (x*x - y*y); }
function y33(x,y,z) { return C[5] * x * (x*x - 3*y*y); }

// Evaluates SH basis functions with degrees up to and including l for the
// given direction d, returning the result as a Float32 array where each
// element is the value of the corresponding basis function.
// Only supports values of l <= 3.
function evalSHBasis(d, l) { 
  const x = d[0];
  const y = d[1];
  const z = d[2];
  switch(l) {
  case 0: return new Float32Array([y00(x,y,z)]);
  case 1: return new Float32Array([
    y00(x,y,z), // l = 0
    y_11(x,y,z), // l = 1
    y01(x,y,z),
    y11(x,y,z)]);
  case 2: return new Float32Array([
    y00(x,y,z), // l = 0
    y_11(x,y,z), // l = 1
    y01(x,y,z),
    y11(x,y,z),
    y_22(x,y,z), // l = 2
    y_12(x,y,z),
    y02(x,y,z),
    y12(x,y,z),
    y22(x,y,z)]);
  default: return new Float32Array([
    y00(x,y,z), // l = 0
    y_11(x,y,z), // l = 1
    y01(x,y,z),
    y11(x,y,z),
    y_22(x,y,z), // l = 2
    y_12(x,y,z),
    y02(x,y,z),
    y12(x,y,z),
    y22(x,y,z),
    y_33(x,y,z), // l = 3
    y_23(x,y,z),
    y_13(x,y,z),
    y03(x,y,z),
    y13(x,y,z),
    y23(x,y,z),
    y33(x,y,z)]);
  }
}
```

在编写处理球谐函数的代码时，你很可能会从某处复制粘贴基函数。在这样做时出错（或者源本身就不正确）是可能的。事实上，在我准备这篇文章时，这种情况就发生在我身上。

幸运的是，验证你所拥有的基函数并不困难。记住，球谐基的一个基本属性是它应该是正交归一的：任何基函数与其自身的内积应该是 1，而任何基函数与其他任何不同的基函数的内积应该是 0。

这些内积是容易使用最简单的蒙特卡洛实现进行数值计算的积分。

这是我用来验证上面列出的基函数的代码。

```javascript
// Helper to multiply SH coefficients by a scalar value.
function mulScalarBySHCoeffs(scalar, coeffs) {
  return coeffs.map(function(c){return scalar*c;});
}

// Helper to add together two packs of SH coefficients.
function addSHCoeffs(coeffs0, coeffs1) {
  return coeffs1.map(function(c,i){
    return c + (coeffs0.length==0 ? 0 : coeffs0[i]);
  });
}

// Uses simple Monte-Carlo integration to verify that the basis functions
// are orthonormal.
function testBasisFunctions() {
  const numSamples = 100000;
  const numBasisFuncs = 16; // we support l up to and including 3, so 16 funcs.
  
  // innerProducts[i] contains the inner products of the i-th 
  // SH basis function with every SH basis function, including itself.
  var innerProducts = [];
  for (var b = 0; b < numBasisFuncs; ++b) {
    // these arrays will be initialized to 0.
    innerProducts.push(new Float32Array(numBasisFuncs));
  }
  
  for (var s = 0; s < numSamples;) {
    // Generate a random point on a sphere using simple rejection sampling: 
    // * Generate a point within the [-1,-1,-1] - [1,1,1] cube;
    // * If the point is inside the unit sphere, normalize and use it;
    // * Otherwise, try again.
    var xr = Math.random()*2.0-1.0;
    var yr = Math.random()*2.0-1.0;
    var zr = Math.random()*2.0-1.0;
    var n = Math.sqrt(xr*xr+yr*yr+zr*zr);
    if (n>1) continue;
    s++;
    var d = new Float32Array([xr/n, yr/n, zr/n]);
    
    // Evaluate every SH basis function on the generated sample point,
    // compute the partial inner products and add them to the running totals.
    const basisFunctionValues = evalSHBasis(d, 3);
    for (var b = 0; b < numBasisFuncs; ++b) {
      const bv = basisFunctionValues[b];
      const partialInnerProducts = 
        basisFunctionValues.map(function(v) { return v * bv; });
      innerProducts[b] = addSHCoeffs(innerProducts[b], partialInnerProducts);
    }
  }
  
  // Final step in Monte-Carlo integration: multiply by the measure of the 
  // integration domain (4pi in the unit sphere case) divided by number of
  // samples.
  for (var b = 0; b < numBasisFuncs; ++b) {
    innerProducts[b] = 
      mulScalarBySHCoeffs(4*Math.PI/numSamples, innerProducts[b]);
  }
  
  // innerProducts[i][j] should be very close to 1 if j==i and very close to 0 
  // otherwise.
  console.log(innerProducts);
}
```

上述多项式函数相当简单。你可以直接使用它们，而无需考虑球谐函数的实际数学定义。然而，如果你想稍微加深对这一主题的理解，就有必要探究这些函数是如何产生的。我们将在接下来的几节中推导它们。

### 定义

我一直觉得在球谐函数的数学定义和上面简单的代码之间架起桥梁是一件令人头疼的事情。

如果你查找“球谐函数基函数”，或者翻阅一些数学教科书，你可能会遇到这个吓人的家伙作为次数为 $\ell$ 和阶为 $m$ 的球谐函数的定义：
$$
Y_{\ell}^{m}(\theta,\varphi)=(-1)^{m}\sqrt{ \frac{2\ell+1}{4\pi} \frac{(\ell-m)!}{(\ell+m)!} }P_{\ell}^{m}(\cos\theta)e^{im\varphi}
$$

我现在就告诉你，这并不是计算机图形中通常使用的形式。然而，我们使用的形式包含了所有相同的构建模块。因此，我们将逐一拆解上面的公式，孤立地检查每一部分，以更好地理解它。

 关于 $Y_{\ell}^{m}(\theta,\varphi)$ 首先要注意的一点是，它是一个用球面坐标定义的函数。这很合理：毕竟，我们处理的是定义在球面上的函数。现在是一个建立一些坐标系约定的好时机。这样做非常重要。不同的作者可能会假设不同的约定。因此，例如，当你复制和粘贴代码时，你必须意识到原来使用的约定，以及你要粘贴到的目标代码假设的约定。

这是我们即将使用的惯例。它与 Green 的球谐函数论文中的惯例相同。

![image.png](https://raw.githubusercontent.com/SilverStr1ng/Images/master/Images/20260415154037.png)

我们将假设角度 $\theta$ 是 $Z$ 轴与我们的方向向量之间的角度，而 $\phi$ 是 $X$ 轴与我们的方向向量在 $XY$ 平面上的投影之间的角度。因此，从球面坐标转换为笛卡尔坐标的转换公式为：
$$
\begin{aligned}
x &= \cos \phi \sin \theta \\
y &= \sin \phi \sin \theta \\
z &= \cos \theta
\end{aligned}
$$

> [!TIP] 注释
> 为了防止歧义，这里要注意 $\phi$ = $\varphi$

处理完坐标系的问题后，让我们回到我们的定义上来。首先，我们将处理这个烦人的 $(-1)^{m}$ 因子。这个东西有一个花哨的名字：“**康登-肖特利相位**(<font color="#4dfe50">Condon-Shortley phase</font>)”。实际上我们可以直接去掉它。在许多领域，它通常被忽略，而且往往连在定义中都不包含。就我所见，在计算机图形学中，它大多被忽略，尽管我确实见过至少一个代码库似乎包含了它。但我们为什么可以随意包含或忽略这一部分呢？

那个问题在我第一次遇到球谐函数时让我感到困惑，但从那时起我找到了一个合理的答案。以下是我自己对为何可以舍弃康登-肖特利相位的一种直观理解：球谐函数是基函数。将它们乘以-1 并不会改变它们能做什么。

让我们回顾一下向量。在经典的 3D 空间中，向量 (1,0,0)、(0,1,0) 和 (0,0,1) 构成一个基，同样，向量 (-1,0,0)、(0,1,0) 和 (0,0,-1) 也构成一个基。那么如果我们翻转其中一些向量的符号会怎样呢？同样的逻辑也适用于这里：乘以-1 并不会改变 SH 的“基性”或其他性质：函数与其自身的内积仍然是 1，函数与其他所有函数的内积仍然是 0。乘以-1 只会影响表示给定函数所需的系数（类似于在 3D 空间中，同一个点会根据我们使用左手坐标系还是右手坐标系而有不同的坐标）。在物理学中的某些应用中，康登-肖特利相位实际上很重要，但对我们来说，它将不再相关。只需知道这是一个概念，当你在实际中遇到它时不要感到惊讶。

接下来，我们简要看一下平方根下的表达式。
$$
\sqrt{ \frac{2\ell+1}{4\pi} \frac{(\ell-m)!}{(\ell+m)!}}
$$

虽然平方根和阶乘让它看起来有些复杂，但这里并没有太多特别之处：本质上，它只是一个**用于归一化的常数**（记住，SH 基是正交归一的）。也就是说，如果我们移除这个常数，内积 $\langle Y_{\ell}^{m},Y_{\ell}^{m} \rangle$ 将不再等于 1。

接下来，我们将审视这个神秘的 $P_{\ell}^{m}(\cos\theta)$

这是一种称为“连带勒让德多项式”或“连带勒让德函数”的东西。$m$ 实际上是一个上标，而不是幂运算！

在球谐函数的上下文中，包含连带勒让德多项式的部分定义了函数如何从极点到极点变化（因为它取决于极角 $\theta$）。

形式上，
$$
P_{\ell}^m(x) = 
\begin{cases} 
(1-x^2)^{\frac{m}{2}} \frac{d^m}{dx^m} P_{\ell}(x) & \text{when } m \ge 0  \\ 
\frac{(\ell-m)!}{(\ell+m)!} P_{\ell}^{-m}(x) & \text{when } m < 0 \quad  
\end{cases}
$$

其中 $P_{\ell}(x)$ 是勒让德多项式（非缔合型），其由公式给出：
$$
P_{\ell}(x)=\frac{1}{2^{\ell}\ell!} \frac{d^{\ell}}{dx^{\ell}}[(x^2-1)^{\ell}]
$$

请注意，一些文献喜欢在缔合勒让德多项式的定义中引入康登-肖特利相位——我们在这里不这样做。

纯粹为了练习，我们可以尝试推导：
$$
P_{1}(x)=\frac{1}{2}\left[ \frac{d}{dx}(x^2-1) \right]=\frac{1}{2}(2x)=x
$$
$$
P_{1}^{1}(x)=\sqrt{ (1-x^2) }\frac{d}{dx}P_{1}(x)=\sqrt{ (1-x^2) }\frac{d}{dx}x=\sqrt{ (1-x^2) }
$$

为了在球谐函数中使用，我们代入 ：
$$
P_{1}^1(\cos \theta)=\sqrt{ 1-\cos^{2}\theta }=\sqrt{ \sin^{2}\theta }=\sin \theta
$$

你大概明白了。我们实际上不需要推导每个连带勒让德函数。下面列表中的内容足以覆盖计算机图形学中的几乎任何应用：

$$
$$
P_{1}^{0}(\cos \theta)=\cos \theta
$$
$$
P_{1}^{1}(\cos \theta)=\sin \theta
$$
$$
P_{2}^{0}(\cos \theta)=\frac{1}{2}(3\cos^2\theta-1)
$$
$$
P_{2}^{1}(\cos \theta)=3\cos \theta \sin \theta
$$
$$
P_{2}^{2}(\cos \theta)=3\sin^2\theta
$$
$$
P_{3}^{0}(\cos \theta)=\frac{1}{2}(5\cos^3\theta-3\cos \theta)
$$
$$
P_{3}^{1}(\cos \theta)=\frac{3}{2}(5\cos^2\theta-1)\sin \theta
$$
$$
P_{3}^{2}(\cos \theta)=15\cos \theta \sin^2\theta
$$
$$
P_{3}^{3}(\cos \theta)=15\sin^3\theta
$$
$$
P_{4}^{0}(\cos \theta)=\frac{1}{8}(35\cos^4\theta-30\cos^2\theta+3)
$$
$$

这里需要注意几点。

首先，不要被三角函数的出现迷惑：一旦从球坐标转换到笛卡尔坐标，这些函数就会变成多项式形式。

其次，这些公式来源于维基百科的相关条目，不过那里收录的版本还包含康登-肖特利相位。我已在此处将其移除。

第三，你会注意到这份列表仅包含正 m 值的条目——稍后将阐明原因。

最后要提的一点是，你可能已经猜到，我们上面给出的"定义"远非故事的全貌。它缺乏关于这些函数背后数学原理的宏观背景——而这正是球谐函数的真正核心。

连带勒让德函数之所以呈现现在的形式，是因为它们实际上是一个名为连带勒让德方程的微分方程的解。不幸的是，详细描述并求解这个方程远远超出了本文的范围。当然，要在计算机图形学中应用球谐函数，你并不需要了解这一部分。

这正是计算机图形学采用略有不同的球谐函数形式的主要原因。我们目前看到的定义实际上是复数域球谐函数的定义：这类函数可用于近似"返回"复数值的表达式，在物理学中应用广泛。

但在计算机图形学中，我们通常不处理复数值函数。当然，我们可以简单地将实数值函数视为虚部恒为零的复数值函数，但这并不太方便。

幸运的是，存在一种更适合实数值函数的定义方式。此外，复数域球谐函数可以用实数值球谐函数来表示，反之亦然。

### 这次是真正的（实数域）定义

在 Robin Green 的论文摘录中，可以找到关于实值球谐函数简洁明确的定义：

……球谐函数传统上用符号 $y_{\ell}^{m}$ 表示：
$$
y_{\ell}^{m}(\theta,\phi) = 
\begin{cases} 
\sqrt{ 2 }K_{\ell}^m\cos(m\phi)P_{\ell}^m(\cos \theta) & \text{if } m > 0  \\ \\
K_{\ell}^0P_{\ell}^0(\cos \theta)& \text{if } m =0 \\
\sqrt{ 2 }K_{\ell}^m\sin(-m\phi)P_{\ell}^{-m}(\cos \theta) & \text{if } m < 0 \quad  
\end{cases}
$$

其中，$P_{\ell}^m$ 是我们之前探讨过的连带勒让德多项式，而 $K_{\ell}^m$ 只是归一化参数的缩放因子：
$$
K_{\ell}^m=\sqrt{ \frac{(2\ell+1)}{4\pi}\frac{(\ell-|m|)!}{(\ell+|m|)!} }
$$

可以肯定地说，99.999%的计算机图形学论文在提及“球谐函数”时指的就是这个定义。

此定义复用了前文提及的所有基本组成部分，因此这些内容应该都已经很熟悉了。不过，仍有几个重要细节需要指出。

首先，请注意归一化常数有所不同：它使用了阶数的绝对值。这与复数情形的定义形成对比——复数情形中，归一化常数直接使用阶数本身！

第二点需要注意的是，在 $m<0$ 的情况下，我们会在正弦函数和对应的缔合勒让德多项式中把 $m$ 的符号取反。也正因为如此，上面列出的缔合勒让德多项式只包含 $m$ 为正的情况：我们不需要单独列出 $m$ 为负的情况。

### 导出基函数

现在我们可以尝试推导实数球谐函数的一些基函数。

先看 $y_{0}^{0}$ 的情况。根据上述定义，$y_{0}^0(\theta,\phi)=K_{0}^0P_{0}^0(\cos \theta)$。

其中，$K_{0}^0=\sqrt{ \frac{1}{4\pi} }$，这很容易验证，而根据前面引用的连带勒让德多项式表，$P_{0}^0(\cos \theta)=1$。因此，$y_{0}^0(\theta,\phi)=\sqrt{ \frac{1}{4\pi} }$ 只是一个常数（也称为 0 次多项式）。

那么 $y_{1}^{-1}$ 呢？同样地，根据上述定义, $y_{1}^{-1}(\theta,\phi)=\sqrt{ 2 }K_{1}^{-1}\sin \phi P_{1}^{1}(\cos \theta)$。

$K_{1}^{-1}=\sqrt{ \frac{3}{4\pi}\frac{1}{2} }$，而 $P_{1}^1(\cos \theta)=\sin \theta$。

2 的平方根相互抵消，因此我们得到：$y_{1}^{-1}(\theta,\phi)=\sqrt{ \frac{3}{4\pi} }\sin \phi \sin \theta$。

从球坐标转换到笛卡尔坐标时（使用我们之前约定的惯例），有：$y=\sin\phi\sin\theta$。因此，笛卡尔坐标下的最终结果就是：$y_1^{-1}(x,y,z)=\sqrt{\frac{3}{4\pi}}y$。这比我们一开始使用的公式简单得多！另外注意，在函数参数中，我们把 $\theta$、$\phi$ 改成了 $x,y,z$ 以反映坐标系的变化。

使用完全相同的步骤，可以证明 $y_{1}^0(x,y,z)=\sqrt{ \frac{3}{4\pi} }z$ 和 $y_{1}^1(x,y,z)=\sqrt{ \frac{3}{4\pi} }x$。

作为最后一个例子，让我们做一点更复杂的运算 $y_{2}^2$： 通过化简并展开连带勒让德多项式，我们得到：
$$
y_{2}^2(\theta,\phi)=\sqrt{ 2 }\sqrt{ \frac{4+1}{4\pi}\frac{(2-|2|)!}{(2+|2|)!} }\cos(2\phi) P_{2}^2(\cos \theta)=\sqrt{ \frac{5}{48\pi} }\cos(2\phi) P_{2}^2(\cos \theta)=\sqrt{ \frac{5}{48\pi} }\cos(2\phi)3\sin^2\theta
$$ 
我们将这个恼人的 3 移到根号下并进一步化简：
$$
\sqrt{ \frac{5}{48\pi} }\cos(2\phi)3\sin^2\theta=\sqrt{ \frac{5*9}{48\pi} }\cos(2\phi) \sin^2\theta=\sqrt{ \frac{5*3}{16\pi} }\cos(2\phi) \sin^2\theta=\frac{1}{4}\sqrt{ \frac{15}{\pi} }\cos(2\phi) \sin^2\theta
$$

根据三角学知识，我们知道 $\cos(2\phi)=(2\cos^2\phi-1)$ 且 $\sin^2\theta+\cos^2\theta=1$：
$$
\frac{1}{4}\sqrt{ \frac{15}{\pi} }\cos(2\phi) \sin^2\theta=\frac{1}{4}\sqrt{ \frac{15}{\pi} }(2\cos^2\phi-1)\sin^2\theta=\frac{1}{4}\sqrt{ \frac{15}{\pi} }(2\cos^2\phi \sin^2\theta-\sin^2\theta)=\frac{1}{4}\sqrt{ \frac{15}{\pi} }(2\cos^2\phi \sin^2\theta-1+\cos^2\theta)
$$

现在我们可以将已得到的结果用笛卡尔坐标重新表示：
$$
\frac{1}{4}\sqrt{ \frac{15}{\pi} }(2\cos^2\phi \sin^2\theta-1+\cos^2\theta)=\frac{1}{4}\sqrt{ \frac{15}{\pi} }(2x^2+z^2-1)
$$

我们可以利用单位球面上的事实，稍微整理一下结果：
$$
\frac{1}{4}\sqrt{ \frac{15}{\pi} }(2x^2+z^2-x^2-y^2-z^2)=\frac{1}{4}\sqrt{ \frac{15}{\pi} }(x^2-y^2)
$$

因此，最终得到：
$$
y_{2}^2(x,y,z)=\frac{1}{4}\sqrt{ \frac{15}{\pi} }(x^2-y^2)
$$

完成这个练习，有助于理解我们是如何从看似复杂的数学定义，推导出本文之前展示的简单多项式形式的。当然，你不需要逐一推导所有内容。目前已有球谐函数表可供参考。我推荐查阅 [Peter-Pike Sloan 的《Stupid Spherical Harmonics Tricks》论文中的附录 A 2](https://www.ppsloan.org/publications/StupidSH36.pdf)，其中包含了高达五阶的笛卡尔坐标系下的 SH 基函数，而且据我所知没有任何拼写错误。

## 获取球谐系数

至此，我们应当对球谐函数有了一个基本理解。我们也明白了，任何分段连续实值函数 都可以表示为一个无穷级数：
$$
f(\theta,\phi)=c_{0}^0y_{0}^0(\theta,\phi)+c_{1}^{-1}y_{1}^{-1}(\theta,\phi)+c_{1}^0y_{1}^{0}(\theta,\phi)+c_{1}^1y_{1}^1(\theta,\phi)+\dots
$$

其中 $y_{\ell}^m$ 是实值球谐函数 ，$c_{\ell}^m$ 是其对应的系数。我们仍需回答的问题是：对于任意给定的 $f(\theta,\phi)$，如何求出这些 $c_{\ell}^m$ 系数？换言之，如何将图像的立方体贴图表示转化为近似的球谐函数系数集合？

要回答这个问题，我们再次回顾向量/线性空间的类比。假设有一个三维向量 $\overrightarrow{v}$，以及一个基 $\overrightarrow{i},\overrightarrow{j},\overrightarrow{k}$。如何计算 $\overrightarrow{v}$ 在由 $\overrightarrow{i},\overrightarrow{j},\overrightarrow{k}$ 定义的参考系中的坐标？

答案是：我们只需要计算内积（或点积）$\overrightarrow{v}\cdot \overrightarrow{i}$, $\overrightarrow{v} \cdot \overrightarrow{j}$, $\overrightarrow{v}\cdot \overrightarrow{k}$，分别对应 $\overrightarrow{v}$ 在 $\overrightarrow{i},\overrightarrow{j}$ 和 $\overrightarrow{k}$ 方向上的投影长度。实际上，如果你回想一个向量如何通过矩阵从一种坐标空间转换到另一种坐标空间，其本质无非就是计算这些点积。

将类似的逻辑应用于函数的情况，要计算系数 ，我们必须计算内积：
$$
\langle f,y_{\ell}^{m}\rangle=\int f(\overrightarrow{\omega})y_{\ell}^m(\overrightarrow{\omega})d\overrightarrow{\omega}
$$

这个积分通常通过数值计算完成，我们将在下一节演示其具体实现方法。

## 案例研究：将立方体贴图投影到球谐函数基上

我们从实际示例开始，探讨如何使用球谐函数近似立方体贴图定义的辐射度。我们将选取一个小型立方体贴图，生成相应的球谐系数，使得在评估这些系数时能近似还原立方体贴图的内容。

请记住，要计算立方体贴图投影的球谐系数 $c_{j}^{i}$，我们需要计算 $\int T(\overrightarrow{\omega})y_{\ell}^{m}(\overrightarrow{\omega})d\overrightarrow{\omega}$，其中 $T$ 是立方体贴图定义的辐射度函数，而 $y_{\ell}^m$ 是对应的球谐基函数。

如何实现这一点？为了回答这个问题，让我们先看一个仅涉及单变量实值函数的示例。

假设我们有一个任意函数，如下图所示，计算其积分有哪些方法？

![image.png](https://raw.githubusercontent.com/SilverStr1ng/Images/master/Images/20260506155306.png)

如果函数是以闭合形式给出的，我们或许能通过[微积分基本定理](https://en.wikipedia.org/wiki/Fundamental_theorem_of_calculus)来计算积分，但这显然对我们没什么用：我们的辐射度函数并非以闭合形式给出。

实际上，情况还要更糟。使用立方体贴图时，我们能获取的函数信息非常有限。事实上，我们只拥有规则网格上固定数量的采样点（纹素）。如果以同样的方式给出一个单变量函数，它看起来会像这样：

![image.png](https://raw.githubusercontent.com/SilverStr1ng/Images/master/Images/20260506155408.png)

我们该如何计算其积分呢？或许可以再次尝试蒙特卡洛方法，并应用最近邻或线性滤波来重建采样点之间的数值。不过，对于这种情况，这种方法其实并非最优。那些熟悉数学分析的读者，可能仅凭上图就已经得出了答案—— [黎曼和](https://en.wikipedia.org/wiki/Riemann_sum)。

黎曼和的方法你可能在基础分析课程中学过。 你可能之前在一元函数中使用过它，但它也能推广到更高维度：
- 将积分区域划分成互不重叠的部分（对一元函数而言，这些部分是一维区间）；
- 针对每个部分：
	- 在该部分内任选一点，计算函数在该点的值；
	- 将上述结果乘以该部分的“测度”（对一元函数来说，是区间的长度；对于定义在二维区域上的函数，则可能是面积）。
- 将每个部分的累加结果相加，就得到了该积分的近似值。

对于单变量函数来说这很简单，但我们的情况要复杂一些。我们的积分域是球体。通过将每个立方体贴图像素投射到球体上，将球体分割成若干部分：每个投射出的曲面片就是一个独立的"部分"。

但与一维情况不同，计算这些曲面片的面积并非易事。这些面积与对应立方体贴图像素所张成的立体角成正比，并且不同曲面片的面积可能各不相同。下图有助于直观理解该问题：

![image.png](https://raw.githubusercontent.com/SilverStr1ng/Images/master/Images/20260506155535.png)

想象球体内切于立方体贴图，立方体贴图像素被投射到球体表面。上图说明，尽管蓝色和绿色像素在立方体贴图上尺寸相同，但它们投射到球面上的面积实际上并不相等。

实际上有一种相对简单的方法可以计算这些投影的面积，[罗里·德里斯科尔（Rory Driscoll）的这篇文章](https://www.rorydriscoll.com/2012/01/15/cubemap-texel-solid-angle/)对此讲解得非常透彻，因此我这里就不再重复解释了。

在彼得-派克·斯隆（Peter-Pike Sloan）的 [《愚蠢的球谐函数技巧》](https://www.ppsloan.org/publications/StupidSH36.pdf) 论文中，有一种更简单的估算面积方法，但精度稍逊一筹。

综上所述，我们的策略如下：
- 假设立方体贴图适配在 $(-1,-1,-1)$ 到 $(1,1,1)$ 的立方体内；
- 假设我们的积分区域——一个单位球体——被内接于该立方体中；
- 对于立方体贴图每个面上的每个纹素：
	- 获取纹素的值 $T(p)$；
	- 将纹素中心 $p$ 投影到球体表面，得到点 $p'$；
	- 在该点处计算球谐基函数的值 $y_{0}^0(p'),\dots y_{\ell}^{\ell}(p')$;
	- 计算投影贴片的面积 $S_{p'}$；
	- 计算乘积 $t_{0}^{0}=T(p)y_{0}^{0}(p')S_{p'},\dots,t_{\ell}^{\ell}=T(p)y_{\ell}^{\ell}(p')S_{p'}$ 并将其加到相应的累加和 $c_{0}^{0},\dots,c_{\ell}^{\ell}$ 中；
- $c_{0}^{0},\dots,c_{\ell}^{\ell}$ 现在已经包含我们寻求的球谐函数系数

将这一方法转化为 JavaScript 后，代码如下所示：
```javascript
const CUBE_DIM = 128;
const TEXEL_SIZE = 1.0 / CUBE_DIM; // texel size in UV space.
const HALF_TEXEL_SIZE = 0.5 * TEXEL_SIZE;

// Projects a given cube map to spherical harmonics of degrees up to 
// and including maxDegree.
function projectCubemapToSH(cube, maxDegree, gammaCorrection = false) { 
  // Computes the solid angle subtended by the given texel.
  // Derivation:
  // https://www.rorydriscoll.com/2012/01/15/cubemap-texel-solid-angle/
  function calcTexelWeight(x,y) {
    const x0 = x - TEXEL_SIZE;
    const y0 = y - TEXEL_SIZE;
    const x1 = x + TEXEL_SIZE;
    const y1 = y + TEXEL_SIZE;
    function areaElement(a, b) {
      return Math.atan2(a*b, Math.sqrt(a*a + b*b + 1));
    }
    return areaElement(x0, y0) - areaElement(x0, y1) - areaElement(x1, y0) 
          + areaElement(x1, y1);
  }
  
  // We treat each of the red, green and  blue channels as a separate
  // function to approximate.
  // Thus, our output will be three sets of SH coefficients:
  // for red, green and blue respectively.
  var shRgb = [ 
  [],[],[]
  ];
  
  for(var face = 0; face < 6; ++face) {
    for (var col = 0; col < CUBE_DIM; ++col) {
      for (var row = 0; row < CUBE_DIM; ++row) {
        const texelColor = cube[face].data.slice(
            4*(col + row * CUBE_DIM),
            4*(col + row * CUBE_DIM) + 4);
        // UV (0,0) is the top-left corner of the image.
        // UV (1,1) is the bottom-right.
        const faceCoords = cubemapFaceCoords(col, row);
        const d = cubemapCoordsToDirection(face, faceCoords);
        const texelWeight = calcTexelWeight(faceCoords[0], faceCoords[1]);
        const sh = evalSHBasis(d, maxDegree, 1);
        const texelColorf_raw = new Float32Array([
          texelColor[0]/255.0,
          texelColor[1]/255.0,
          texelColor[2]/255.0])
        const texelColorf = 
          gammaCorrection ? srgbToLinear(texelColorf_raw) : texelColorf_raw;
        const shRed = mulScalarBySHCoeffs(texelWeight * texelColorf[0], sh);
        const shGreen = mulScalarBySHCoeffs(texelWeight * texelColorf[1], sh);
        const shBlue = mulScalarBySHCoeffs(texelWeight * texelColorf[2], sh);
        shRgb[0] = addSHCoeffs(shRgb[0], shRed);
        shRgb[1] = addSHCoeffs(shRgb[1], shGreen);
        shRgb[2] = addSHCoeffs(shRgb[2], shBlue);        
      }
    }
  }   
  return shRgb;
}
```

这里需要注意两点。首先是 `calcTexelWeight` 函数。如前所述，该函数用于计算立方体贴图像素所对应的立体角，这对确保积分结果的正确性至关重要。强烈建议阅读相关文章，了解该权重函数有效性的详细解释。我已通过验证所有权重之和趋近于 $4\pi$ 进行了确认。

第二个关键点是 `gamma correction` 参数。通常，若要将立方体贴图投影到球谐函数，需要处理存储实际辐射亮度值的 HDR 立方体贴图（通常由渲染引擎生成）。但在本例中，所有立方体贴图数据均采用 sRGB 编码的 SDR 图像格式存储。因此，我添加了伽马校正输入的可选功能。该操作采用标准的幂运算（数值的 2.2 次方）实现，此处不再赘述代码。

最后，`cubemapFaceCoords` 和 `cubemapCoordsToDirection` 这两个函数用于计算指向特定立方体贴图像素中心的单位向量。虽然正确实现它们至关重要，但其本身并不十分有趣，你可以通过查看完整示例源码来了解它们的具体实现。

我们需要的最后一步是实际计算球谐函数对目标函数的近似表达。给定球谐系数后，如何获取函数的近似值呢？原理其实很简单：

```javascript
// Evaluates the given SH representation of a function projected onto 
// l-band basis in the given direction.
function evalSHRepresentation(coeffs, d, l) {
  // evaluate each basis function for the given direction.
  const basis = evalSHBasis(d, l);
  
  // multiply the values of the basis functions in the given direction
  // with the respective SH coefficients.
  const basis_coefs = coeffs.map(function(c,i) { return c * basis[i]; });
  
  // add up the results.
  return basis_coefs.reduce(function(a, v) { return a+v; }, 0.0);  
}
```

该示例使用这一流程将球谐函数表示转换回可供用户查看的立方体贴图。

## 球谐伪影

到目前为止，我们一直假设将任意函数投影到有限阶球谐基上，是一种在实践中有足够实用价值的"近似"。但遗憾的是，事情并不总是这么简单。

如果你在开启伽马校正的情况下观察 $\ell=1$ 横滨立方体贴图，会发现近似结果在底部存在一个奇怪的"空洞"：
![image.png](https://raw.githubusercontent.com/SilverStr1ng/Images/master/Images/20260506160421.png)

凸显负值区域后会发现一个有趣的现象：我们的球谐表示在很多区域的计算结果都小于零。

![image.png](https://raw.githubusercontent.com/SilverStr1ng/Images/master/Images/20260506160442.png)

伽马校正会让问题更严重，但它并不是导致这些伪影出现的必要条件。例如，在 $\ell=3$ 中展示的金门大桥立方体贴图，即使未经伽马校正，也包含负值：

![image.png](https://raw.githubusercontent.com/SilverStr1ng/Images/master/Images/20260506160501.png)

那么问题出在哪里？我们的原始立方体贴图根本没有负值，为何近似结果会生成负值？而伽马校正又为何似乎会加剧这个问题？

回想一下之前的论述：任何在球面上定义的连续实值函数 都能表示为无穷级数：
$$
f(\theta,\phi)=c_{0}^{0}y_{0}^{0}(\theta,\phi)+c_{1}^{-1}y_{1}^{-1}(\theta,\phi)+c_{1}^{0}y_{1}^{0}(\theta,\phi)+c_{1}^{1}y_{1}^{1}(\theta,\phi)+\dots
$$

这是一个无可争议的数学事实。 然而，在实际应用球谐函数时，我们往往忽略了两个至关重要的条件：首先，我们使用的是有限子集而非无限基函数；其次，我们经常尝试投影那些不规则甚至可能不连续的函数（例如我们的立方体贴图）。

数学可不会宽容这种越界行为。它会用可怕的"**振铃**(<font color="#4dfe50">ringing</font>)"或"**吉布斯现象**(<font color="#4dfe50">Gibbs phenomena</font>)"来惩罚我们。当这种情况发生时（通常是因为输入函数存在急剧变化或间断点），我们所谓的"近似"会在问题区域周围产生剧烈的过冲/下冲。即便我们试图近似的函数严格保持正值，计算近似值时仍可能得到负数！可以想象，这对光照渲染来说简直是灾难性的——毕竟世界上根本不存在"负数"光。

这也解释了为什么开启伽马校正会让问题更严重：线性化数值会加剧暗部与亮部之间的反差，使函数更容易产生振铃现象。

为了解决这个问题，我们的第一反应可能是添加更多频带。然而，所需系数的数量呈二次方增长，这使得该方法很快变得不切实际。更重要的是，不连续函数就像一个具有无限频率的信号，因此无论你添加多少频带，都无法保证结果不会出现负值。

处理该问题的常用方法（由 Sloan 的论文提出）是将投影系数乘以另一组系数，这组系数会随着对应频带次数 $\ell$ 的增加而逐渐衰减至零。论文将这一过程称为“加窗”。定义加窗系数随频带次数递减的函数被称为“**窗函数**(<font color="#4dfe50">windowing function</font>)”。

本例中使用的窗函数是 [sinc](https://en.wikipedia.org/wiki/Sinc_function)：
$$
W_{\ell} = 
\begin{cases} 
1 & \text{when } \ell = 0  \\ 
\left( \frac{\sin(\pi\ell/q)}{\pi\ell/q} \right)^p & \text{when } \ell > 0 \quad  
\end{cases}
$$

其中 $q$ 是一个控制加窗系数随 $\ell$ 增长而衰减至零速率的参数，而 $p$ 则用于控制去振铃效果的"强度"（后文将详述）。

但这一方法为何能奏效？在数字信号处理领域中，球谐函数被称为"频域表示"。它通过将任意信号表示为不同频率已知信号的加权叠加——频带次数 $\ell$ 越高，对应频率也越高。

应用加窗函数可视为逐步降低高频分量对输出的影响，即实施一种低通滤波操作。这本质上等同于对输入信号进行"模糊"处理。当然，这种模糊处理会削弱信号的剧烈变化与不连续性——代价则是获得细节较少的输出结果。

因此，这种去振铃方法实际上只是对输入信号进行“模糊”处理，以消除导致振铃伪影的不连续性。窗口函数的 $q$ 参数控制模糊的“宽度”（即应截止的频率范围），而 $p$ 参数则控制模糊的生效次数——有时只应用一次不足以消除所有负值。

## 案例研究：将辐照度投影到球谐函数

在下一个示例中，我们将探讨如何将辐照度投影到球谐函数上。这里参考了 Yuriy O'Donnel 在 GDC 2018 上的演讲《[Frostbite 中的预计算全局光照](https://media.contentapi.ea.com/content/dam/eacom/frostbite/files/gdc2018-precomputedgiobalilluminationinfrostbite.pdf)》，具体关注其中关于光照贴图中漫反射光照的章节。

### 球谐函数与光照贴图

你可能已经知道，光照贴图是一种特殊的纹理，用于存储场景中每个表面点上接收到的光照量。 “光照量”这个说法有些含糊。通常，光照贴图存储的是某个点上辐照度的近似值，即以下积分：
$$
E(p)=\int L_{i}(\overrightarrow{\omega},p)\max(0,\overrightarrow{\omega}\cdot \overrightarrow{n})d \overrightarrow{\omega}
$$

其中 $p$ 是表面上的点，$L_{i}(\overrightarrow{\omega},p)$ 是从方向 $\overrightarrow{\omega}$ 到达 $p$ 的光线， 而 $\overrightarrow{n}$ 是该点 $p$ 的表面法线。

实际上，这正是 Frostbite 在相关演讲中所使用的光照贴图实现所采用的量：
> 我们在光照贴图中使用低阶L1球谐函数来存储辐照度数据。

但等等，辐照度与球谐函数之间究竟有何关联？

若固定表面点 $p$，辐照度也可视为该点处表面法线的函数：
$$
E(\overrightarrow{n})=\int L_{i}(\overrightarrow{\omega},p)\max(0,\overrightarrow{\omega}\cdot\overrightarrow{n})d \overrightarrow{\omega}
$$

这是一个定义在球面上的函数。寒霜引擎的演示表明，他们存储的是该函数的球谐系数（最高至第 1 阶），并在运行时根据实际着色法线对其求值。但将辐照度存储为表面法线的函数意义何在？

当网格使用法线贴图时，烘焙光照需捕捉法线贴图呈现的细节。若仅存储固定值，烘焙光照将呈现平面效果。下图清晰展示了这一点：阴影区域虽通过光照贴图接收到间接光照，但任何由法线贴图引起的细节变化都完全丢失了。

![图片来源：Matt Pettineo](https://raw.githubusercontent.com/SilverStr1ng/Images/master/Images/20260506161730.png)

你可能会说：这其实很容易解决——只需在离线计算中纳入从法线贴图中提取的表面法线即可！虽然这在理论上可行（尽管这会阻止你在运行时扰动着色法线），但它有一个相当大的缺点：光贴图的每个纹素必须对应法线贴图的一个纹素。

是的，你的光贴图会有更多细节，但它们也会更大（且烘焙更慢）。相反，你可以生成较低分辨率的光贴图，但让每个纹素包含一个函数的近似值，该函数告诉我们：如果该点的表面法线朝向特定方向，该点的辐照度会是多少。

因此，通过让光贴图将辐照度存储为表面法线的函数，我们：
- 使烘焙光照能够响应法线贴图的内容；
- 允许在运行时扰动法线；
- 减少所需空间和烘焙时间

这正是 Frostbite 演示中运用球谐函数所实现的效果。

### 球谐函数与卷积

以下是该演示文档中计算辐照度球谐函数表示的过程描述：
> 为了进行渲染，我们需要计算从表面法线方向周围半球所有方向照射到该表面上的光量。换句话说，我们需要计算几何体表面特定点的辐照度。
> 
> 这通过将球谐函数形式的辐射度函数与[...]截断余弦函数进行卷积来实现。
> 
> 球谐函数是信号的频域表示，这种形式的卷积就是对球谐基函数因子进行简单的逐分量乘法。

要理解这一点，我们需要探讨另一个数学概念——**卷积**(<font color="#4dfe50">convolution</font>)——并研究它如何与球谐函数相互作用。请耐心阅读接下来的几段内容，您很快就会发现这与辐照度之间的关联。

您可能已经熟悉图像处理中的卷积概念，即让一个系数矩阵（"滤波器"）在图像上"滑动"，同时将图像中的数值与滤波器中对应的数值相乘，并将所有结果累加求和。

这一概念可推广至函数领域。对于笛卡尔坐标系中定义的函数 $f$ 和 $g$，卷积运算 $(f*g)$ 的定义非常直观。

$$
(f*g)(t)=\int f(\tau)g(t-\tau)d\tau
$$

可以看到，笛卡尔坐标系中的卷积本质上就是将其中一个函数"滑动"到另一个函数之上，将两者相乘后对结果进行积分。换句话说，要计算在点 $t$ 处的卷积值，我们先让其中一个函数（称为"卷积核"，在上述定义中由 $g$ 承担此角色）以点 $t$ 为中心"居中"，再将该居中后的核函数与另一个函数的乘积进行积分。

然而，我们当前处理的函数定义在球面上，因此上述卷积定义并不完全适用。由于我们需要让函数在球面上"滑动"，这个定义必须进行相应调整。

假设我们在球面上定义了两个函数 $f(\overrightarrow{\omega})$ 和 $g(\overrightarrow{\omega})$。此外，定义 $\rho_{t}(g)$ 为函数 $g$ 经过"旋转"后的结果，使该函数的"北极"与方向 $t$ 对齐。那么 $f$ 与 $g$ 的卷积定义为：
$$
(f*g)(t)=\langle f, \rho_{t}(g) \rangle= \int f(\omega)(\rho_t g)(\omega)d\omega
$$

此处的旋转操作替代了笛卡尔坐标系中"居中"的步骤。

最后，我们来看球谐函数与卷积相关的一个有趣性质。

假设 $f_{\ell}^{m}$ 是函数 $f$ 对应的球谐系数。进一步假设 $h$ 是一个绕 $Z$ 轴旋转对称的函数（即当方位角改变时，其值不变）。那么，卷积 $f*h$ 的球谐系数可以通过以下公式求得：
$$
(f*h)_{\ell}^{m}=\sqrt{ \frac{4\pi}{2 \ell +1} }f_{\ell}^mh_{\ell}^0
$$

为什么我们要关注卷积及其球谐系数？再来看一下辐照度积分：
$$
E(\overrightarrow{n})=\int L_{i}(\overrightarrow{\omega},p)\max(0,\overrightarrow{\omega}\cdot\overrightarrow{n})d \overrightarrow{\omega}
$$

本质上，$\overrightarrow{\omega}\cdot\overrightarrow{n}$ 就是 $g(\theta,\phi)=\cos \theta$ 经过旋转后，使其"北极"与表面法线 $\overrightarrow{n}$ 对齐的结果。一旦理解这一点，就能立刻明白辐照度是辐射亮度 $L_{i}$ 与余弦函数（确切地说是"截断"余弦）卷积的结果。

### 计算辐照度的球谐系数

我们已经知道如何获取辐照度的球谐系数。之前提到的"截断余弦"函数拥有广为人知的球谐系数。你可以在 Ramamoorthi 和 Hanrahan 的论文《辐照度环境贴图的高效表示》中找到它们：
$$
A_{0}=\frac{\sqrt{ \pi }}{2}, A_{1}=\sqrt{ \frac{\pi}{3} }
$$

那这样就结束了吗？只需要把辐射亮度投影到 $\ell=0,1$ 的球谐函数上，然后将 $\ell=0$ 频带中的系数乘以 $A_0$ ​，将 $\ell=1$ 频带中的系数乘以 $A_1$ ​，这样就完事了吗？

这个方法确实可行，但我们还能稍作优化。Frostbite 的演示为我们展示了一个巧妙技巧，能让评估步骤得以简化。回顾一下，要计算卷积的球谐系数，我们必须这样做：
$$
(f*h)_{\ell}^m=\sqrt{ \frac{4\pi}{2\ell+1} }f_{\ell}^{m}h_{\ell}^0
$$

对于辐照度情形，我们的函数是辐射度 $L_{i}$ 和截断余弦函数，记作 $A$：
$$
(L_{i}*A)_{\ell}^{m}=\sqrt{ \frac{4\pi}{2\ell+1} }L_{\ell}^mA_{\ell}^0
$$

我们来尝试对 $(L_{i}*A)_{0}^{0}$ 进行简化。 鉴于 $A_{0}=\frac{\sqrt{ \pi  }}{2}$，可得：
$$
(L_{i}*A)_{0}^{0}=\sqrt{ 4\pi }L_{0}^{0} \frac{\sqrt{ \pi  }}{2}=\pi L_{0}^{0}
$$

由于 $L_{0}^{0}$ 是 $y_{0}^{0}$ 与不同辐射度值乘积的和， 我们可以提取常数项：$L_{0}^{0}=\frac{1}{2\sqrt{ \pi }}(\dots)$。 因此：
$$
(L_{i}*A)_{0}^{0}=\pi\frac{1}{2\sqrt{ \pi }}(\dots)=\frac{\sqrt{ \pi }}{2}(\dots)
$$

但已知在运行时求值过程中，我们需要将该值再次乘以 $y_{0}^{0}$，而该系数包含恒定因子。那么为何不直接将常数因子 $\frac{1}{2\sqrt{ \pi }}$ 合并到辐照度计算中呢？
$$
\frac{1}{2\sqrt{ \pi }}(L_{i}*A)_{0}^{0}=\frac{1}{2\sqrt{ \pi }}\frac{\sqrt{ \pi }}{2}(\dots)=\frac{1}{4}(\dots)
$$

其他推导过程可以在 [PDF](https://media.contentapi.ea.com/content/dam/eacom/frostbite/files/gdc2018-precomputedgiobalilluminationinfrostbite.pdf) 中查阅，但结论是：我们可以将辐射度投影、卷积和部分评估合并为一个简短的函数：

```cpp
SHL1 shEvaluateDiffuseL1(vec3 p)
{
  float AY0 = 0.25f;
  float AY1 = 0.50f;
  SHL1 sh;
  sh[0] = AY0;
  sh[1] = AY1 * p.y;
  sh[2] = AY1 * p.z;
  sh[3] = AY1 * p.x;
  return sh;
}
```

该函数返回的值将存储在光照贴图中，最精妙之处在于，针对给定的法线进行评估时，只需与法线进行点积运算！所有其他计算已在烘焙步骤中完成。
